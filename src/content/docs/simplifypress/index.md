SimplifyPress is in design. This page exists so the documentation URL is stable
from day one — bookmark it and it will fill in rather than move.

## What it will cover

- **Installation** — one plugin, no server access, and what it does not change.
- **Review policies** — deciding which changes need a preview and who signs
  them off, without blocking the changes that never needed review.
- **Previews** — how a draft including template and block changes is rendered
  from the live site without a staging environment.
- **Update batches** — grouping plugin and theme updates into one reviewable
  set, with a visual diff of key pages.
- **Rollback** — what a snapshot contains, what it restores, and what it cannot.
- **The change log** — the record you can hand to a client.

## Shaping it

The hard part is previewing template and block changes on a live site without a
staging copy. If you maintain WordPress sites professionally and have opinions
about where that breaks, we want them.
