SimplifyCommerce is in design. This page exists so the documentation URL is
stable from day one — bookmark it and it will fill in rather than move.

## What it will cover

- **Connecting channels** — Shopify, WooCommerce and marketplace listings.
- **The rule vocabulary** — triggers, conditions and actions, and how to test a
  rule against real historical orders before it goes live.
- **Multi-channel stock** — how one stock truth is reconciled across channels
  and what happens when two channels sell the last unit at the same moment.
- **Supplier handoff** — dropship and 3PL formats, and acknowledgement tracking.
- **Reconciliation** — matching payouts against orders, refunds and fees.

## Shaping it

The rule vocabulary is the part worth arguing about while it is still cheap to
change. If you run a store with routing logic that current tools handle badly,
we would like to hear the specifics.
