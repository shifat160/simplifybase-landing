- SimplifyGuide replaces SimplifyFlow in the family: record any WordPress task as a step-by-step guide with screenshots, then walk people through it on the real screen with Show me.
- Smart Blur pixelates email addresses, phone and card numbers, IP and MAC addresses and API keys before a screenshot is uploaded.
- Exports to MP4 and WebM video, GIF, PDF, Word, HTML, Markdown and JSON; embed block, shortcode and public links.
- Voice narration, annotations, AI rewriting with your own provider, and version history.
- Setup wizard, Overview dashboard and a rebuilt settings screen.
- Guides recorded without a title are named from their steps.
- Beta open.
